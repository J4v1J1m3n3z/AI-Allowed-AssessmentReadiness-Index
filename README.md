# Descriptive: 
The AI-Allowed Assessment Readiness Index is a research project surrounding the question if State-approved K-12 assessmnets can be completed effectively by Gen AI. This is not a cheat detection project but more focused on the design of current State assessments importantance when gen AI is popular.
